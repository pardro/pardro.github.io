소속 / 주최
한국거래소
담당
주가 예측 모델링 · 매매 알고리즘 구축
기술 / 방법
SCINet · Time Series Forecasting · Blocked Cross Validation

배경과 과제

과거 주가에서 미래 수익률을 예측하는 모델을 만들고, 예측 결과를 실제 종목 선정과 매매 규칙으로 연결하는 과제였습니다. 시계열의 순서와 최신 정보의 반영, 종목별 변동성을 함께 고려해야 했습니다. 예측값만으로 종목을 선택하기보다 과거 변동성과 미래 수익률 예측을 결합한 전략을 구성했습니다.

구현 구조

종목 선정금융 업종 · 52개 종목
→
수익률 예측과거 32일 → 3일 후
→
매매 전략예측 수익률 · 변동성

종목 구성과 입력 데이터

금융 업종을 그룹화하고 이상치와 변동성을 고려해 52개 종목을 선별했습니다. 과거 32일의 주가 데이터를 입력으로 사용해 3일 후의 수익률을 예측하는 시계열 문제로 구성했습니다.

SCINet 학습과 검증 방식 조정

SCINet을 커스터마이징해 수익률 예측 모델을 학습했습니다. Blocked Cross Validation을 조정해 최신 정보의 가중치를 높이고, 입력과 추론 값의 차이를 줄이는 방법을 적용했습니다.

점수 기반 종목 선정과 매매

과거 주가 변동성과 미래 예측값을 점수화해 상승 가능성이 높은 종목을 선정했습니다. 선정한 종목을 매수하고 3일 뒤 매도하는 운용 전략으로 예측과 매매를 연결했습니다.

담당 업무

시계열 예측 모델링

과거 32일과 3일 후 수익률의 관계를 학습하도록 SCINet을 커스터마이징했습니다. 종목 구성부터 입력 데이터와 예측 목표를 정의하고 시계열 모델 학습을 수행했습니다.

최신 정보를 반영한 검증

시계열 특성에 맞춰 Blocked Cross Validation을 조정했습니다. 최신 정보에 더 높은 가중치를 주고 입력과 추론 값의 차이를 줄이는 방식으로 예측 과정을 개선했습니다.

매매 알고리즘 구축

예측 수익률과 과거 주가 변동성을 함께 점수화하는 종목 선정 로직을 구성했습니다. 매수 후 3일 뒤 매도하는 규칙으로 모델의 예측 결과를 운용 전략에 반영했습니다.

결과와 기여

2023년 11월 23일 한국거래소가 주최한 제2회 KRX 주식투자 알고리즘 경진대회에서 최우수상(1위)을 수상했습니다. 시계열 예측 모델의 학습·검증과 종목 선정·매매 규칙을 함께 구성하며 예측 모델을 운용 로직으로 연결했습니다.
