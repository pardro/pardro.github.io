석사학위논문 · 2026

Gzip 압축기술과 K-NN 알고리즘을 사용한 준지도학습 한국어 문장 분류 방법

신호영 · 한양대학교 인공지능융합대학원 인공지능시스템학과

연구 배경

소량의 레이블 데이터와 다량의 비레이블 데이터를 활용해 한국어 문장 분류 성능을 개선하는 준지도학습 방법을 연구했습니다.

방법

Gzip 압축 기반 유사도와 K-NN을 결합해 비레이블 데이터의 확률적 의사 레이블을 생성했습니다. 실제 레이블의 학습 손실과 의사 레이블의 학습 손실을 결합하고, 학습 단계에 따른 가중치 스케줄링으로 의사 레이블의 영향력을 조절했습니다.

유사도 계산Gzip · K-NN
→
의사 레이블확률적 레이블 생성
→
모델 학습손실 결합 · 가중치 조절

실험

KLUE-YNAT, K-MHaS, NSMC 데이터셋에서 BERT 및 LLM 기반 분류 모델에 대한 적용 효과를 분석했습니다.

결과와 한계

일부 데이터셋에서는 분류 성능이 개선됐지만, 미세한 문맥 차이가 중요한 감성 분류에서는 한계가 나타났습니다. 원문을 변형하지 않고 비레이블 데이터를 활용하는 가능성과 함께, 데이터 특성과 모델 구조에 맞는 학습 전략의 필요성을 확인했습니다.
