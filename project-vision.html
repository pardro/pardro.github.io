배경과 과제

고객사와 경쟁사 제품에 대한 소셜데이터에는 제품 속성과 긍정·부정 반응이 함께 나타납니다. 한 문장에 여러 속성이 포함될 수 있어 단일 카테고리 분류만으로는 정보를 충분히 정리하기 어려웠습니다. 자연어 데이터를 속성과 감성으로 구조화하고, 분석 결과를 마케팅 의사결정에 활용할 수 있도록 제공하는 것이 목적이었습니다.

제품·경쟁사 키워드 기반 데이터

고객사의 제품과 경쟁사 관련 키워드를 바탕으로 수집한 소셜데이터를 분석 대상으로 삼았습니다. 자유로운 문장에 담긴 제품 반응을 속성과 감성 관점에서 분류할 수 있도록 구성했습니다.

감성·속성 자동 분류

KoBERT 기반 딥러닝 모델을 활용해 제품별 감정 분류와 카테고리 멀티라벨 분류를 수행했습니다. 한 문장에 여러 제품 속성이 포함되는 경우에도 다차원 분류 결과로 구조화했습니다.

분석과 마케팅 리포팅

모델의 분류 Output을 바탕으로 데이터를 분석하고 고객사와 경쟁사 제품에 대한 반응을 정리했습니다. 분석에서 확인한 인사이트를 마케팅 제언과 의사결정 지원 보고서로 연결했습니다.

담당 업무

자연어 분류 모델 개발

KoBERT를 활용한 감정 분류 및 카테고리 멀티라벨 분류 모델을 개발했습니다. 단순한 키워드 집계가 아니라 문장 수준의 자연어 정보를 분류 결과로 전환하는 역할을 수행했습니다.

분류 결과 기반 데이터 분석

자동 분류된 속성과 감성 정보를 후속 분석에 활용했습니다. 고객사 제품과 경쟁사 제품을 분석하고 마케팅 관점에서 활용할 수 있는 주요 반응과 인사이트를 정리했습니다.

인사이트 도출과 제언

모델 개발에 그치지 않고 분류 결과를 고객사의 의사결정에 활용할 수 있는 리포트로 작성했습니다. 기술적인 분류 결과를 제품·마케팅 관점의 분석과 제언으로 전달했습니다.

결과와 기여

소셜데이터를 제품 속성과 감성으로 자동 분류하고, 그 결과를 마케팅 인사이트와 제언 보고서로 연결했습니다. 자연어 처리 모델의 Output이 실제 비즈니스 분석과 의사결정 자료로 활용되는 전체 과정을 수행했습니다.
