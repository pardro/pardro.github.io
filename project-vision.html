COMPUTER VISION / ML

이미지 분류 파이프라인

이미지 데이터를 정리하고, 분류 모델의 학습과 추론 과정을 연결한 프로젝트.

기간
2025.10 — 2025.12
역할
팀 3인 · 데이터 및 모델링
기술
PyTorch, OpenCV, MLflow

문제

이미지의 크기와 촬영 조건이 제각각이고 일부 분류에 데이터가 편중돼 있었습니다. 데이터 정리 기준을 맞추고, 같은 조건에서 모델을 비교할 수 있는 학습 흐름을 만들었습니다.

구조

Dataset정제 · 분할
→
Training학습 · 기록
→
Inference분류 · 검토

구현

데이터 정리

손상 이미지와 중복 파일을 확인하고 분류별 데이터 구성을 점검했습니다. 같은 원본에서 나온 이미지가 학습과 검증 데이터에 섞이지 않도록 분할했습니다.

모델 비교

전이 학습 모델을 기준으로 이미지 크기와 데이터 증강 조건을 비교했습니다. 실험 설정과 모델 파일을 MLflow에 기록했습니다.

추론 연결

학습 시 사용한 전처리를 추론 단계에서도 동일하게 적용했습니다. 결과와 신뢰도를 반환하고, 오류가 잦은 이미지를 따로 확인할 수 있도록 했습니다.

검증

전체 정확도와 함께 분류별 정밀도와 재현율을 확인했습니다. 혼동 행렬을 바탕으로 자주 혼동하는 분류를 찾고 원본 이미지와 라벨을 다시 검토했습니다.

남은 과제

새로운 촬영 환경에서는 성능 변화가 생길 수 있습니다. 학습에 사용하지 않은 환경에서 데이터를 추가로 모아 확인할 예정입니다.
