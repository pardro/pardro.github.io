데이터 통합

세 개 앱의 GA 데이터를 통합하고 페이지별 고객 행동에서 유의한 변수를 추출했습니다.

모델 비교

여러 모델의 성능을 비교했으며 XGBoost가 상대적으로 우수한 결과를 보였습니다.

일반화 검토

테스트 데이터에 대한 일반화가 어렵다는 한계를 확인했습니다. 과적합 문제에 대응하고 GA 수집기 개선을 진행했습니다.

결과

행동 데이터 기반 예측 모델의 가능성과 한계를 검토했습니다. 모델 비교 결과만으로 운영 성능을 단정하지 않고 데이터 수집과 일반화 문제를 함께 다뤘습니다.
