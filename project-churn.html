앱 행동 기반 대출 이탈 예측

은행·카드 기업의 앱 행동 데이터를 활용한 대출 신청 및 이탈 예측 PoC.

담당
GA 데이터 통합 · 변수 추출 · 예측 모델 PoC
기술 / 방법
Google Analytics · XGBoost · Feature Engineering

배경과 과제

은행·카드 기업이 운영하는 세 개 앱에 축적된 GA 데이터에서 고객의 대출 신청과 이탈 행동을 설명하는 패턴을 찾는 과제였습니다. 서로 다른 앱의 행동 데이터를 통합하고 페이지별 행동을 예측 변수로 만드는 작업이 필요했습니다. PoC에서는 모델 성능 비교와 함께 테스트 데이터에서도 결과를 일반화할 수 있는지 검토하는 것이 중요했습니다.

구현 구조

세 개 앱의 GA 데이터 통합

고객사가 운영하는 세 개 앱의 GA 데이터를 통합했습니다. 앱과 페이지별로 축적된 고객 행동을 분석하고 신용대출 신청과 이탈 예측에 활용할 수 있는 데이터 기반을 마련했습니다.

행동 변수 추출과 모델 비교

페이지별 행동 패턴에서 유의한 변수를 추출하고 예측 모델을 개발했습니다. 여러 모델의 성능을 비교했으며, 실험에서는 XGBoost가 상대적으로 우수한 결과를 보였습니다.

일반화 검토와 수집 개선

테스트 데이터에 대한 일반화가 어렵다는 한계를 확인했습니다. 모델 비교 결과만으로 서비스 적용 가능성을 단정하지 않고, 과적합 문제 대응과 GA 수집기 개선을 함께 진행했습니다.

담당 업무

행동 데이터 분석과 변수 설계

GA 데이터 통합과 고객 행동 분석을 수행하고 페이지별 행동 정보를 예측 변수로 구성했습니다. 단순 방문 기록을 모델에 활용 가능한 Feature로 전환하는 작업을 담당했습니다.

예측 모델 PoC 수행

신용대출 신청·이탈 예측을 위한 모델링과 성능 비교를 수행했습니다. XGBoost 등 여러 모델의 실험 결과를 비교해 데이터에서 확인할 수 있는 예측 가능성을 검토했습니다.

과적합과 데이터 한계 검토

테스트 데이터에서 일반화가 어려운 점을 확인하고 모델의 한계를 분석했습니다. 과적합 대응과 GA 수집기 개선을 진행하며 모델 구조뿐 아니라 입력 데이터의 수집 방식까지 함께 검토했습니다.

결과와 기여

앱 행동 데이터를 통합하고 대출 신청·이탈 예측 PoC를 수행했습니다. XGBoost의 상대적인 성능 우위와 테스트 데이터 일반화의 한계를 함께 확인했으며, 운영 성능을 단정하는 대신 데이터 수집 개선과 후속 검증이 필요한 지점을 정리했습니다.
