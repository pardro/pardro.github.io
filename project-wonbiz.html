담당 업무

검색과 생성 분리

질문 분리·최적화와 답변 생성 역할을 나눴습니다. 서로 다른 두 개의 LoRA 어댑터를 위한 학습 데이터를 증강하고 각각 튜닝했습니다.

문서 검색 커스터마이징

플랫폼의 많은 메뉴와 사용자 권한을 고려해 문서 검색 파이프라인을 구성했습니다. 현재 화면에 맞는 상대적인 안내를 할 수 있도록 학습 데이터를 구축했습니다.

모델 서빙 연결

Embedding과 Reranker를 검색 흐름에 적용하고 vLLM 기반 서빙으로 답변 생성을 연결했습니다. 스트리밍 응답과 세션 상태를 고려한 서비스 구조를 설계했습니다.

결과

서비스 모델 설계와 제작을 담당하며, 질의 최적화·문서 검색·답변 생성을 연결한 챗봇 구조를 구현했습니다.
