원비즈플라자 챗봇

기업용 구매·공급 플랫폼의 메뉴와 사용 방법을 안내하는 LLM 챗봇.

담당
서비스 모델 설계 · 학습 데이터 구축 · 모델 튜닝
기술 / 방법
LoRA · Embedding · Reranker · vLLM

배경과 과제

원비즈플라자는 기업의 구매·공급 업무를 처리하는 플랫폼으로 메뉴가 많고 사용자 권한에 따라 안내 범위가 달라집니다. 같은 질문도 현재 화면과 이전 대화에 따라 의미가 달라질 수 있어, 단순한 FAQ 검색을 넘어 화면 맥락과 권한을 고려한 안내가 필요했습니다. 사용자 편의성과 관리자의 안내 업무 부담을 함께 고려한 챗봇 구축을 진행했습니다.

질문 분리와 최적화

현재 화면 정보와 대화 맥락을 바탕으로 질문을 분리·최적화합니다. 해당 역할을 담당하는 LoRA 어댑터를 별도로 학습해 검색에 적합한 질의로 연결했습니다.

플랫폼 문서 검색

Embedding 검색과 Reranker를 활용해 관련 문서를 찾는 파이프라인을 구성했습니다. 대량의 메뉴와 사용자 권한을 고려해 검색 흐름을 커스터마이징하고 화면에 맞는 상대적인 안내를 지원했습니다.

답변 생성과 스트리밍

답변 생성용 LoRA 어댑터에 검색 결과를 전달하고 vLLM 서빙을 통해 응답을 생성합니다. SSE 기반 스트림 처리와 세션 유효 시간, 오류·Timeout 응답을 고려한 서비스 연결 구조를 설계했습니다.

담당 업무

서비스 모델 설계와 제작

챗봇의 서비스 모델 설계와 제작을 담당했습니다. 질문 처리, 문서 검색, 답변 생성의 역할을 나누고 프런트엔드·백엔드와 서빙 API 사이의 응답 흐름을 구성했습니다.

역할별 데이터 증강과 LoRA 튜닝

질문 분리·최적화와 답변 생성을 서로 다른 두 LoRA 어댑터로 분리했습니다. 각 역할에 맞춰 학습 데이터를 증강하고 튜닝했으며, 현재 화면 정보를 활용하는 안내를 위해 모델 학습 데이터를 구축했습니다.

검색과 모델 서빙 연계

Embedding·Reranker 기반 검색을 답변 생성과 연결하고 vLLM 기반 서빙으로 구성했습니다. 멀티턴 상담과 권한별 정보 안내, 스트리밍 응답을 함께 고려해 플랫폼 사용 흐름에 맞는 구조를 구현했습니다.

결과와 기여

질의 최적화와 답변 생성의 역할을 분리하고, 문서 검색과 모델 서빙을 연결한 기업용 플랫폼 챗봇을 구축했습니다. 모델 튜닝뿐 아니라 화면 맥락, 권한, 세션과 응답 처리까지 고려하며 실제 서비스 사용 흐름에 맞춰 설계했습니다.
