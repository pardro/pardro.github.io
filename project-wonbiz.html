원비즈플라자 챗봇

사용설명서 기반의 자체 학습 데이터와 복합질문 처리로 기업용 플랫폼의 메뉴·사용 방법을 안내하는 챗봇.

기술 / 방법
Synthetic Data · Query Decomposition · LoRA · Embedding · Reranker · vLLM

배경과 과제

원비즈플라자는 기업의 구매·공급 업무를 처리하는 플랫폼으로, 메뉴가 많고 사용자 권한에 따라 안내 범위가 달라집니다. 사용자가 여러 질문을 한 번에 하는 경우가 많아 복합질문을 의도별로 분리하고 검색에 적합한 질의로 정리할 필요가 있었습니다. 서비스 사용설명서를 바탕으로 두 종류의 학습 데이터를 자체 증강하고, 화면·대화 맥락을 반영한 검색과 답변 구조를 함께 설계했습니다.

복합질문에 맞춘 학습 데이터 자체 증강

원비즈플라자 사용자는 여러 메뉴나 기능에 대한 질문을 한 번에 묻는 경우가 많았습니다. 복합적인 질문을 그대로 검색에 전달하기보다, 의도별로 분리하고 각 질문을 검색에 최적화된 질의로 만드는 구조가 필요했습니다.

이에 서비스 사용설명서를 기반으로 학습 데이터를 자체 증강했습니다. 문서를 먼저 증강해 데이터의 다양성을 확보한 다음, 다양한 고객 페르소나의 사용 맥락에 맞춰 질문과 대화를 제작했습니다. 데이터는 ‘질문최적화/분리’와 ‘질의응답’의 두 목적에 맞춰 구성했습니다.

질문최적화/분리: 하나의 발화에서 여러 검색 질의로

여러 의도가 섞인 복합질문을 의도별로 나누고, 나누어진 질문을 검색에 적합한 형태로 정리하는 데이터를 제작했습니다. 질문을 단순히 짧게 바꾸는 것이 아니라, 복수의 질문을 구분해 필요한 정보를 찾을 수 있도록 하는 데 초점을 맞췄습니다.

질의응답: 사용설명서에 근거한 서비스 안내

증강한 서비스 사용설명서와 다양한 고객 페르소나를 활용해 질의응답 데이터를 구축했습니다. 플랫폼의 메뉴·기능·사용 방법에 대한 안내를 학습하도록 구성하고, 질문 분리·최적화와 답변 생성에 필요한 데이터를 각각의 역할에 맞춰 제작했습니다.

목적별로 분리한 두 가지 학습 데이터셋

단계별 데이터 가치 판단

문서 증강과 페르소나별 데이터 구축 과정의 각 단계에 데이터 가치 판단자를 배치했습니다. 생성한 데이터의 가치를 평가하고 결과를 품질 개선에 반영해, 데이터 다양성과 학습 목적에 맞는 품질을 함께 높였습니다.

폐쇄 서버 기반 가상 고객 시뮬레이션

1차 서비스 파이프라인을 구축한 뒤 챗봇을 폐쇄 서버에 배포하고, 가상의 고객 페르소나가 서비스를 사용하는 프로세스를 제작했습니다. 생성한 학습 데이터뿐 아니라 실제로 구성한 질문 처리·검색·답변 파이프라인 안에서 서비스의 대응을 확인했습니다.

검증에서 발견한 부족한 점을 강화학습 데이터로

가상 고객이 서비스를 사용하는 과정에서 부족한 점을 찾아내고, 이를 후속 모델의 강화학습 데이터로 활용했습니다. 사용설명서 기반 데이터 증강, 역할별 모델 학습, 폐쇄 환경의 서비스 검증을 연결해 학습 데이터를 지속적으로 확보하는 고도화 과정을 구성했습니다.

챗봇이 안내하는 기업용 플랫폼

구현 구조

복합질문 분리와 검색 질의 최적화

현재 화면과 대화 맥락을 고려하면서 복합질문을 의도별로 분리하고 검색에 최적화된 질의로 변환합니다. 질문최적화/분리 데이터셋으로 별도 학습한 LoRA 어댑터를 사용해 질문 처리와 답변 생성의 역할을 나눴습니다.

플랫폼 문서 검색

Embedding 검색과 Reranker를 활용해 관련 문서를 찾는 파이프라인을 구성했습니다. 대량의 메뉴와 사용자 권한을 고려해 검색 흐름을 커스터마이징하고 화면에 맞는 상대적인 안내를 지원했습니다.

답변 생성과 스트리밍

답변 생성용 LoRA 어댑터에 검색 결과를 전달하고 vLLM 서빙을 통해 응답을 생성합니다. SSE 기반 스트림 처리와 세션 유효 시간, 오류·Timeout 응답을 고려한 서비스 연결 구조를 설계했습니다.

담당 업무

사용설명서 기반 데이터 증강

서비스 사용설명서를 먼저 증강하고 다양한 고객 페르소나별 학습 데이터를 제작했습니다. 질문최적화/분리와 질의응답 데이터셋을 나누고, 각 단계의 데이터 가치 판단을 통해 품질을 높였습니다.

역할별 LoRA와 검색·생성 설계

복합질문의 의도별 분리·검색 최적화와 답변 생성을 두 개의 LoRA 어댑터로 분리해 학습했습니다. 플랫폼 메뉴·사용자 권한·현재 화면의 맥락을 고려한 문서 검색과 답변 흐름을 설계했습니다.

폐쇄 서버 검증과 학습 데이터 환류

1차 서비스를 폐쇄 서버에 올리고 가상 고객 페르소나가 서비스를 사용하는 프로세스를 제작했습니다. 이 과정에서 서비스의 부족한 점을 발견하고 후속 모델의 강화학습 데이터로 활용했습니다.

서빙과 서비스 연결

Embedding·Reranker 기반 검색과 vLLM 서빙을 연결했습니다. 멀티턴 상담, 스트리밍 응답, 세션 유효 시간과 오류 처리를 고려하며 서비스 모델 설계·제작을 담당했습니다.

결과와 기여

서비스 사용설명서의 증강과 다양한 고객 페르소나를 활용해 질문최적화/분리·질의응답 데이터셋을 자체 구축했습니다. 복합질문을 의도별로 나누는 질문 처리와 답변 생성을 별도 LoRA로 학습하고, 검색·서빙을 연결한 챗봇을 구현했습니다. 단계별 데이터 가치 판단과 폐쇄 서버의 가상 고객 검증을 통해 부족한 점을 찾아 후속 모델의 강화학습 데이터로 이어갔습니다.
