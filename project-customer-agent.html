고객센터 직원의 상담을 지원하기 위한 지식 검색과 STT 고도화 프로젝트.

AI Agent · STT · KMS · Python

배경과 과제

고객센터 직원은 상담 중 고객의 질문을 이해하고 업무 지식에서 필요한 정보를 빠르게 찾아야 합니다. 정확한 안내와 응대 시간 단축을 목표로 상담 데이터와 지식 기반을 연결할 필요가 있었으며, 새로운 KMS 구축과 STT 고도화가 함께 진행됐습니다. 고객상담 업무에 AI Agent를 적용하기 위한 데이터·학습·서빙 흐름의 설계가 주요 범위였습니다.

상담 업무와 정보 활용 흐름 정리

고객센터 직원을 사용자로 설정하고 상담 과정에서 필요한 정보 탐색과 지원 업무를 정리했습니다. 고객 상담 데이터와 업무 지식이 활용되는 지점을 중심으로 서비스 요구사항을 구체화했습니다.

STT와 KMS 기반 구성

음성 상담 데이터를 활용하기 위한 STT 고도화와 새로운 KMS 구축을 진행했습니다. 상담 기록과 지식 검색을 상담 보조 업무에 연결할 수 있도록 데이터 수집·활용 흐름을 설계했습니다.

학습·서빙 Agent 파이프라인

고객센터에서 사용할 STT 학습·서빙 관련 Agent 파이프라인을 설계했습니다. 개별 모델의 개발뿐 아니라 상담 업무에서 데이터와 모델이 이어지는 전체 흐름을 검토했습니다.

담당 업무

고객상담 영역 AX 사업 관리

다양한 업무 효율화를 위한 AX 사업 중 고객상담 영역의 사업 관리를 담당했습니다. 고객센터 직원의 상담 지원 목적에 맞춰 업무 요구사항과 개발 범위를 정리했습니다.

STT 고도화와 지식 기반 연계

STT 고도화 및 KMS 구축 과정에서 상담 데이터와 업무 지식을 활용하는 구조를 검토했습니다. 상담 중 정보 탐색을 지원한다는 업무 목표에 맞춰 각 구성 요소의 연결 방향을 설계했습니다.

Agent 파이프라인 설계

STT 학습과 서빙에 관련된 Agent 파이프라인 설계를 담당했습니다. 학습 데이터가 모델 활용 단계로 이어지는 과정을 정리하고, 고객상담 업무에 적용할 수 있는 구조로 구체화했습니다.

결과와 기여

고객상담 영역의 AX 사업 관리와 STT 학습·서빙 관련 Agent 파이프라인 설계를 수행했습니다. 상담 직원의 정보 탐색을 지원하기 위해 음성 상담 데이터와 지식 기반을 함께 고려한 서비스 기반을 설계했습니다.
