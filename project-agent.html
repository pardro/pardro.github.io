AGENT / AUTOMATION

업무 자동화 에이전트

자연어 요청을 받아 자료를 조회하고, 정해진 양식으로 보고서를 작성하는 도구.

기간
2026.01 — 2026.02
역할
팀 4인 · 에이전트 및 API
기술
Python, LangGraph, Docker

문제

보고서를 작성할 때마다 여러 도구에서 자료를 조회하고 같은 양식에 옮기는 작업이 반복됐습니다. 조회부터 초안 작성까지 연결하되, 외부에 영향을 주는 작업은 사용자가 확인하도록 구성했습니다.

구조

Request요청 해석
→
Tools조회 · 가공
→
Report초안 · 확인

구현

작업 흐름 설계

요청 해석, 도구 실행, 결과 검토를 별도 단계로 나눴습니다. 필요한 입력이 빠진 경우 추측해서 실행하지 않고 사용자에게 다시 묻도록 했습니다.

도구 연결

조회 도구의 입력과 출력을 고정된 형식으로 정의했습니다. 실행 중 발생한 오류를 기록하고, 재시도가 가능한 작업만 다시 실행하도록 처리했습니다.

보고서 생성

조회 결과를 공통 데이터 구조로 정리한 뒤 보고서에 반영했습니다. 초안과 확정 단계를 나눠 사용자가 내용을 확인할 수 있도록 했습니다.

검증

정상 요청, 입력 누락, 도구 응답 지연, 중복 요청을 구분해 확인했습니다. 단계별 실행 기록으로 어떤 입력과 조회 결과가 보고서에 반영됐는지 추적했습니다.

남은 과제

새로운 업무를 지원하려면 도구 정의와 보고서 양식이 추가로 필요합니다. 실제 사용 기록을 바탕으로 지원 범위를 넓힐 예정입니다.
