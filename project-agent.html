AI 대출상담원

고객 데이터를 학습에 사용하지 않고, 상품 안내서 기반의 자체 데이터셋과 가상 고객 검증으로 개발한 금융 상담 서비스.

배경과 과제

대출 상담은 고객의 질문 의도, 자금 용도, 담보와 상품 선택 상태에 따라 안내 범위가 달라집니다. 여기에 금융권의 보안 제약으로 고객 데이터를 모델 학습에 활용하기 어렵다는 과제가 있었습니다. 상품 안내 내용을 기반으로 학습 데이터를 자체 구축하는 것과, 금융 업무의 제약·대화 맥락을 반영한 상담 서비스를 설계하는 것을 함께 담당했습니다.

사용자 관점의 답변 설계

PoC 단계부터 실제 고객이라면 어떤 질문을 하고 서비스를 어떻게 사용할지에 중점을 두고 실험했습니다. 특히 스마트폰에서 상담을 읽는 환경을 고려해, 고객이 질문의 핵심 답을 먼저 확인할 수 있도록 답변 형식을 설계했습니다.

포맷 비교와 팀 내 선호도 조사

여러 답변 포맷을 제작해 팀 내 선호도를 조사했습니다. 그 결과 질의에 대한 두괄식 답변 한 문장을 먼저 제시하고, 필요한 경우 뒤에 부연설명 두세 문장을 줄글로 이어가는 형식을 채택했습니다.

지식 주입보다 답변 방식 학습에 집중

초기 서비스에서는 프롬프트 튜닝으로 답변 형식을 조정했고, 이후 직접 모델을 튜닝하면서 원하는 응답 방식을 학습에 반영했습니다. 답변 포맷 학습에서는 모델에 지식을 주입하는 것보다 어떻게 답변할지를 익히게 하는 데 중점을 두었습니다.

출시와 단계별 모델 고도화

최초 오픈부터 두 차례의 주요 고도화까지 개발을 담당했습니다. 모델 규모를 줄인 가장 큰 목적은 사용자가 체감하는 답변 속도를 높이는 것이었습니다.

도메인별 Full Fine-tuning과 모델 병합

27B·12B 모델은 여러 도메인별로 Full Fine-tuning을 진행한 후 병합해 구성했습니다. 모델 병합은 최종 모델의 강건성을 높이기 위한 전략으로 적용했습니다. 학습 데이터는 자체 증강 데이터가 대부분이며, 일반 금융지식, 공격적인 질문에 대한 방어 답변, 주택 관련 정책 정보를 반영하기 위한 지리정보 QA, 의도분류 데이터 등을 함께 활용했습니다.

운영 GPU를 기준으로 한 양자화 실험

운영 GPU에서 문제없이 구동할 수 있도록 정밀도를 조정하며 양자화 실험을 진행했습니다. 모델 크기를 줄이는 과정에서 실제 운영 환경의 자원 제약과 응답 품질을 함께 고려했습니다.

멀티턴과 RAG 처리 속도 최적화

대화 이력 길이 실험

이전 대화를 최대 N턴까지 포함하는 방식으로 모델 학습 실험을 진행했습니다. 대화 이력 길이에 따른 메모리 사용과 답변 성능을 비교하고, 두 조건을 함께 고려해 사용할 대화 범위를 선택했습니다.

질의 최적화와 의도분류의 병렬 처리

검색 성능을 높이기 위해 고객 질문을 검색에 적합한 질의로 최적화하는 단계를 도입했습니다. 이어 의도분류 단계를 추가해 고객의 의도를 더 명확하게 파악하고 답변에 반영했습니다. 이후 질의 최적화와 의도분류를 병렬로 수행하도록 수정해 순차 처리에서 발생하는 대기를 줄였습니다.

2차 고도화의 서비스 Depth 최적화는 이러한 질의 기반 RAG 파이프라인의 개선을 의미합니다. 멀티턴을 지원하는 모델 학습과 함께 전체 파이프라인을 수정해 상담 맥락과 사용자 체감 속도를 함께 다뤘습니다.

답변 품질 평가

골든셋을 제작하고 LLM-as-a-Judge로 답변별 점수를 산출했습니다. 팀 내 구성원이 직접 서비스를 사용하며 정성적으로 평가하는 방식도 병행해, 자동 채점과 실제 사용 과정의 검토를 함께 활용했습니다.

학습 데이터셋 자체 구축

금융권에서는 보안 이슈 등으로 고객 데이터를 모델 학습에 활용하기 어려웠습니다. 이에 고객 데이터 대신 은행에서 판매 중인 대출 상품의 상세 안내 내용을 출발점으로 삼아, 모델 학습에 필요한 멀티턴 QA 데이터를 자체 구축했습니다.

상품 안내 정보의 증강과 페르소나별 대화 생성

고품질이면서 다양한 데이터를 확보하기 위해 실제 상품 안내 정보를 무작위로 증강해 가상 상품들을 먼저 구성했습니다. 이 가상 상품은 학습 데이터의 다양성을 확보하기 위한 기반으로 사용했습니다.

이후 각 상품의 안내 문단을 활용해 다양한 고객 페르소나별 질문과 대화를 만들었습니다. 동일한 상품 정보라도 고객 유형과 대화 맥락에 따라 달라지는 상담을 학습할 수 있도록, 데이터를 세 가지 목적에 맞춰 나누어 제작했습니다.

목적별로 분리한 세 가지 학습 데이터셋

단계별 데이터 가치 판단

데이터를 생성하는 데 그치지 않고, 구축의 각 단계에 데이터 가치 판단자를 배치했습니다. 생성 과정에서 데이터의 가치를 평가하고 그 결과를 품질 개선에 반영해, 다양한 데이터를 확보하는 것과 학습에 사용할 데이터의 품질을 높이는 것을 함께 다뤘습니다.

폐쇄 서버 기반 서비스 시뮬레이션

학습 데이터 구축 이후에는 1차 서비스 파이프라인을 구성하고 서비스를 폐쇄 서버에 올렸습니다. 이어 가상의 고객 페르소나가 서비스를 사용하는 프로세스를 제작해, 실제 서비스 흐름 안에서 상담이 어떻게 이어지는지 확인했습니다.

서비스 검증 결과의 학습 데이터 환류

가상 고객이 서비스를 사용하는 과정에서 부족한 점을 찾아내고, 이를 후속 모델의 강화학습 데이터로 활용했습니다. 상품 안내서 기반의 초기 학습 데이터와 서비스 사용 과정에서 확보한 개선 데이터를 연결해, 데이터 구축부터 서비스 검증까지 이어지는 고도화 과정을 마련했습니다.

구현 구조

의도와 상담 상태 파악

고객 질문에서 상품 질문·일반 질문 등을 구분하고 용도와 담보 정보를 추출합니다. 상품 선택 상태를 함께 확인해 현재 고객이 어떤 상담 단계에 있는지 판단하는 흐름으로 구성했습니다.

상품 지식과 일반 지식 검색

상품이 선택된 경우에는 해당 상품 정보와 질문을 함께 사용해 질의를 정제하고 상품 문서를 검색합니다. 상품을 정하지 않은 경우에는 용도·담보 정보를 활용하거나 일반 대출 지식을 검색하도록 분기했습니다.

답변 생성과 대화 연결

검색된 상품 데이터 또는 일반 문서 데이터를 바탕으로 답변을 생성합니다. 멀티턴과 대화 이어가기 기능을 확장하면서 이전 대화의 정보와 상품 선택 상태가 후속 질문에 연결되도록 고도화했습니다.

담당 업무

학습 데이터 기획·구축

판매 중인 대출 상품의 상세 안내 내용을 바탕으로 가상 상품 증강과 고객 페르소나별 멀티턴 QA 제작을 진행했습니다. 의도분류·질문최적화·질의응답 목적을 구분해 모델 학습 데이터셋을 자체 구축했습니다.

데이터 품질 평가와 서비스 검증

구축 단계별 데이터 가치 판단자를 도입하고, 폐쇄 서버에 올린 1차 서비스를 가상 고객 페르소나로 사용하는 프로세스를 제작했습니다. 서비스의 부족한 점을 찾아 후속 모델의 강화학습 데이터로 연결했습니다.

모델 학습과 상담 구조 설계

첫 출시는 모델 튜닝 없이 70B 모델의 프롬프트 튜닝으로 진행했으며, 이후 두 차례의 고도화에서 전용 모델 학습과 서비스 전반의 구조 설계를 담당했습니다. 질문 의도·용도·담보·상품 선택 여부를 검색 및 답변 흐름에 반영하고, 상품 정보와 고객 질문을 함께 활용하는 질의 정제 과정을 구성했습니다.

출시 이후 고도화

대출 상품 범위 확대, 멀티턴과 대화 이어가기 기능의 고도화를 담당했습니다. 상품 질문과 일반 질문의 검색 대상을 구분하고 금융 업무의 제약과 고객의 정보 탐색 요구를 함께 고려하며 모델·파이프라인을 개선했습니다.

결과와 기여

고객 데이터를 학습에 활용하기 어려운 금융 환경에서, 상품 안내서 기반의 증강과 고객 페르소나를 활용해 세 가지 목적의 학습 데이터셋을 자체 구축했습니다. 단계별 데이터 가치 판단과 폐쇄 서버의 가상 고객 시뮬레이션을 연결하고, 서비스에서 발견한 부족한 점을 후속 모델의 강화학습 데이터로 활용했습니다. 데이터 구축·모델 학습·상담 서비스 설계·검증을 하나의 고도화 과정으로 이어간 경험입니다.
