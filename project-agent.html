서비스 구조 설계

첫 출시 단계부터 서비스 흐름과 전용 모델 학습을 담당했습니다. 상품 관련 질문과 일반 질문을 나누고, 상품 선택 상태에 따라 검색 대상을 달리하는 구조를 설계했습니다.

대화 맥락 처리

의도 분류와 용도·담보 정보 추출을 상담 흐름에 연결했습니다. 상품 정보와 질문을 함께 활용하는 질의 정제 과정을 구성했습니다.

지속적인 고도화

멀티턴과 대화 이어가기 등 상담 기능을 확장하고, 상품 확대에 맞춰 모델과 파이프라인을 개선했습니다.

결과

서비스 설계와 모델 개발 전반을 맡고, 출시 이후에도 상품 범위와 대화 기능을 확장하는 고도화를 수행했습니다.
