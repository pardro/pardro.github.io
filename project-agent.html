기술 / 방법
LLM · RAG · Intent Classification · Multi-turn

배경과 과제

대출 상담은 고객이 특정 상품을 선택했는지, 자금의 용도와 담보가 무엇인지에 따라 필요한 정보가 달라집니다. 상품 설명과 일반 대출 지식을 같은 흐름으로 처리하면 질문에 적합한 답변 범위를 정하기 어렵기 때문에, 고객의 의도와 상담 상태를 구분하는 구조가 필요했습니다. 금융 업무의 제약을 고려하면서도 여러 차례 이어지는 질문에 대응하는 것이 주요 과제였습니다.

AI대출상담원 공개 화면

구현 구조

의도와 상담 상태 파악

고객 질문에서 상품 질문·일반 질문 등을 구분하고 용도와 담보 정보를 추출합니다. 상품 선택 상태를 함께 확인해 현재 고객이 어떤 상담 단계에 있는지 판단하는 흐름으로 구성했습니다.

상품 지식과 일반 지식 검색

상품이 선택된 경우에는 해당 상품 정보와 질문을 함께 사용해 질의를 정제하고 상품 문서를 검색합니다. 상품을 정하지 않은 경우에는 용도·담보 정보를 활용하거나 일반 대출 지식을 검색하도록 분기했습니다.

답변 생성과 대화 연결

검색된 상품 데이터 또는 일반 문서 데이터를 바탕으로 답변을 생성합니다. 멀티턴과 대화 이어가기 기능을 확장하면서 이전 대화의 정보와 상품 선택 상태가 후속 질문에 연결되도록 고도화했습니다.

담당 업무

서비스 설계와 전용 모델 학습

첫 출시 단계부터 서비스 전반의 구조와 전용 모델 학습을 담당했습니다. 질문 의도, 용도·담보 정보, 상품 선택 여부를 서비스 분기 조건으로 구체화하고 분류 결과가 검색·답변 단계에 반영되도록 설계했습니다.

질의 정제와 검색 흐름 개선

상품 관련 질문과 일반 질문의 검색 대상을 분리했습니다. 선택한 상품 정보와 고객 질문을 함께 활용하는 Query Refinement를 적용해 상담 맥락에 맞는 정보를 찾도록 파이프라인을 구성했습니다.

출시 이후 기능 확장

출시 이후에도 대출 상품 범위 확대와 멀티턴, 대화 이어가기 기능의 고도화를 담당했습니다. 금융 상담에서 안내할 수 있는 답변 범위와 고객의 정보 탐색 요구를 함께 고려하며 모델과 서비스 흐름을 개선했습니다.

결과와 기여

단일 상품 지식을 조회하는 방식에서 고객의 의도·용도·담보·상품 선택 상태를 반영하는 상담 구조로 확장했습니다. 서비스 설계와 모델 학습을 함께 담당하며, 출시 이후 기능과 상품 범위가 늘어나는 과정에서도 검색·대화 파이프라인을 지속적으로 고도화했습니다.
