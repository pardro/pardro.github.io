LLM / RETRIEVAL

문서 기반 질의응답

여러 문서에 흩어진 정보를 찾아, 출처와 함께 답변하는 검색 서비스.

기간
2026.03 — 2026.05
역할
개인 · 설계 및 개발
기술
Python, FastAPI, RAG, PostgreSQL

문제

같은 질문에도 필요한 정보가 여러 문서에 나뉘어 있어, 답을 찾으려면 파일을 하나씩 열어야 했습니다. 질문에 맞는 문서 구간을 찾고 원문으로 돌아갈 수 있는 검색 흐름을 만들었습니다.

구조

Documents수집 · 정제
→
Retrieval검색 · 재정렬
→
Answer답변 · 출처

구현

문서 처리

PDF에서 텍스트를 추출하고 문서 제목과 페이지 정보를 함께 저장했습니다. 문단 단위로 나눠 검색 결과가 문맥을 유지하도록 구성했습니다.

검색과 답변

키워드 검색과 벡터 검색을 결합했습니다. 답변에 사용한 문서 구간을 함께 반환하고, 근거가 없는 질문에는 답변을 보류하도록 했습니다.

API 배포

검색과 생성 단계를 분리한 FastAPI 서버를 구성했습니다. 처리 단계별 로그를 남겨 검색 오류와 생성 오류를 따로 확인할 수 있게 했습니다.

검증

문서에 답이 있는 질문과 없는 질문을 나눠 확인했습니다. 검색된 구간이 질문과 관련 있는지, 최종 답변이 원문에 근거하는지를 각각 검토했습니다.

남은 과제

표와 스캔 문서는 텍스트 추출 품질에 영향을 받습니다. 문서 형식별 처리와 검색 평가용 질문 세트를 보완할 예정입니다.
