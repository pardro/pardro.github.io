AI 청약상담원

최신 입주자모집공고를 검색해 청약 관련 질문에 답하는 상담 서비스.

담당
사업 관리 · 검색 파이프라인 설계 · 모델 관리 및 검증
기술 / 방법
RAG · Embedding · Vector DB · LLM

배경과 과제

청약 상담은 긴 입주자모집공고 안에서 지역, 모집공고명, 순위와 같은 조건에 맞는 내용을 찾아야 합니다. 공고마다 신청 자격과 세부 조건이 다르고 새로운 문서가 계속 추가되므로, 문서 최신화와 질문 조건을 반영한 검색을 함께 설계해야 했습니다. 검색한 근거를 대화형 답변으로 연결하는 RAG 서비스가 개발의 중심이었습니다.

AI청약상담원 공개 화면

구현 구조

최신 공고 수집과 문서 갱신

매일 최신 입주자모집공고를 수집하고 공고 형식에 맞춘 전처리를 수행합니다. 전처리한 문서를 청크 단위로 나눠 Vector DB에 업데이트하여 새 공고가 검색에 반영되는 흐름을 구성했습니다.

질문 조건 추출과 검색

질문에서 의도와 공고명·지역·순위 등의 엔티티를 추출합니다. 사용자의 질문을 조건 정보와 함께 검색 단계로 전달하고, 관련 문서에서 상담에 필요한 문맥을 찾도록 연결했습니다.

문맥 기반 답변 생성

질문, 의도, 엔티티, 검색 Context를 프롬프트에 결합해 LLM 답변 생성에 활용합니다. 공고문을 근거로 이어지는 질문에 대응할 수 있도록 멀티턴 상담 파이프라인을 설계했습니다.

담당 업무

사업 관리와 검색 모델 개발

생성형 AI 플랫폼 사업의 청약 상담 서비스 구축 과정에서 사업 관리와 검색 모델 개발을 담당했습니다. 문서 갱신과 질문 조건별 검색이 하나의 서비스 흐름으로 동작하도록 파이프라인을 설계했습니다.

문서 전처리와 RAG 구성

공고문을 검색에 활용할 수 있는 형태로 전처리하고 청크 단위 업데이트를 구성했습니다. 공고명과 지역 등 질문의 주요 정보를 검색 과정에 반영하고, 검색 결과를 답변 생성 단계와 연결했습니다.

모델 학습 관리와 운영 검증

RAG 기반 파이프라인의 모델 학습 관리와 검증을 수행했습니다. 출시 이후에도 검색 모델과 생성 모델을 지속적으로 관리하며 공고문 기반 질의응답 서비스를 고도화했습니다.

결과와 기여

최신 입주자모집공고를 수집·갱신하는 데이터 흐름과, 질문 조건에 맞춰 근거 문서를 검색하는 상담 흐름을 함께 구축했습니다. 문서 검색에서 답변 생성까지의 연결뿐 아니라 출시 이후 모델 관리와 검증 업무도 수행했습니다.
