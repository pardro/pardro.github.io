배경과 과제

예적금 상담은 상품 설명에 답하는 것뿐 아니라 고객 조건을 이해하고 가입 과정까지 이어져야 합니다. 질문의 의도와 상품·우대조건 같은 정보를 별도로 파악하고, 대화 중 수집한 정보를 다음 단계에서 재사용하는 구조가 필요했습니다. 한국어와 금융 도메인에 맞는 모델 학습 데이터, 업무 시나리오와 대화 관리가 함께 요구됐습니다.

AI뱅커 서비스 공개 이미지

구현 구조

언어 이해와 대화 상태 관리

NLU에서 의도 분류와 정보 추출을 수행하고, 발화 정보를 대화 상태에 저장합니다. 추출된 의도와 정보를 답변 생성에서도 재활용해 업무 처리와 대화 맥락을 연결하는 방식으로 설계했습니다.

정책 결정과 업무 처리

대화 상태를 바탕으로 답변 정책과 Task Manager 호출을 결정합니다. 상품 정보 조회, 우대조건 추출, 이자율·만기금액 계산 등 가입 여정에 필요한 업무를 대화 흐름 안에서 연결하는 시나리오를 구성했습니다.

데이터 구성과 모델 적용

한국어 공통 데이터, 금융 업무 데이터, 예적금 가입과 복합대화 등 업무 수행 데이터를 단계적으로 구성했습니다. 대화형 데이터 증강과 크라우드워커 데이터셋 제작을 통해 모델 학습에 사용할 대화 데이터를 마련했습니다.

담당 업무

업무 시나리오와 고객 여정 설계

예금·적금 상품 가입 시나리오를 정의하고 상담에서 가입까지의 여정을 파이프라인으로 설계했습니다. 언어 이해, 상태 관리, 정책 결정, 업무 처리, 답변 생성이 단계별로 연결되도록 구성했습니다.

데이터 증강과 제작 사업 운영

모델 간 대화인 M2M 방식을 활용한 대화형 데이터 증강 알고리즘을 개발했습니다. 크라우드워커 기반 대화형 데이터셋 제작 사업을 운영·관리하고, 한국어와 금융 도메인 및 업무 수행 목적에 맞는 데이터를 제작했습니다.

RAG 구성과 PoC 분석

RAG 기반 QA 응답 모델의 파이프라인 설계와 데이터 구현에 참여했습니다. 자체 PoC 분석과 실험을 수행하며 모델의 범용성과 적용 범위를 검토하고 금융 상담 업무에 맞는 활용 방식을 확인했습니다.

결과와 기여

상품 설명 중심의 질의응답과 실제 가입 업무를 대화형 서비스로 연결하는 시나리오를 설계했습니다. 사업 관리, 데이터 제작, 데이터셋 구축 운영과 PoC 분석을 수행하며 금융 도메인 대화 시스템 개발을 경험했습니다.
