가입 시나리오 설계

예금·적금 상품의 가입 시나리오와 고객 여정을 정의했습니다. 의도 이해, 대화 상태 관리, 답변 정책, 업무 처리, 답변 생성으로 흐름을 구성했습니다.

학습 데이터 제작

한국어와 금융 도메인, 업무 수행에 필요한 데이터를 단계적으로 구성했습니다. 모델 간 대화 생성 방식의 데이터 증강과 크라우드워커 기반 대화형 데이터셋 제작 사업을 운영했습니다.

모델 적용 검증

의도 분류와 정보 추출 결과를 답변 생성에 재활용하는 방식을 적용했습니다. PoC 분석과 실험을 통해 모델의 적용 범위를 검토했습니다.

결과

업무 시나리오 설계와 데이터 제작, 데이터셋 구축 사업 운영을 담당하며 금융 상담용 대화 시스템 개발에 참여했습니다.
